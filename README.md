# SafeLogin - Phone Verification System

Developed by: Muhammad Yasir Khan

## Description
This project is designed to verify users using their phone numbers.

## Features
- User enters phone number
- User chooses SMS or Voice verification
- System sends OTP via SMS or automated voice call

## Opt-in Policy
Users voluntarily provide their phone number and request the verification code themselves.

## Communication Type
- SMS for OTP
- Voice call for OTP

## No Abuse Policy
This project does NOT send:
- Marketing messages
- Bulk messages
- Spam

## Purpose
This project is used for authentication and security only.
